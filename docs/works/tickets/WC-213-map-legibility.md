## 구현 (사용자 피드백: "가시성이 떨어져, semi-3D로 가야 하나?")
- 간선도로가 나누는 12개 구역에 런던 이스트엔드 실제 지명 부여
  (쇼디치/베스널 그린/글로브 타운/보우, 스피탈필즈/화이트채플/스텝니/마일 엔드, 올드게이트/섀드웰/와핑/라임하우스)
- 라벨은 도로·지점과 겹치지 않도록 블록(건물 덩어리) 중앙에 배치 + 외곽선(paint-order)
- 도시 블록 음영을 깔아 도로가 도드라지게, 도로 선 굵기·명도 상향
- semi-3D(아이소메트릭)는 불필요하다고 판단: 좌표 왜곡으로 인접 관계 파악이 오히려 어려워지고
  모바일 성능·터치 정확도에 불리. 2D 평면도 + 지명/음영으로 가독성 목표 달성.
